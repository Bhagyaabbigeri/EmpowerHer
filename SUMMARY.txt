 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1️⃣  GET TWILIO CREDENTIALS
    → Go to: https://www.twilio.com/console
    → Sign up (free account)
    → Copy: Account SID, Auth Token, Phone Number

2️⃣  CONFIGURE ENVIRONMENT
    → Create .env.local with credentials:
    
    VITE_TWILIO_ACCOUNT_SID=ACxxxxx...
    VITE_TWILIO_AUTH_TOKEN=your_token_here
    VITE_TWILIO_PHONE_NUMBER=+1234567890
    VITE_BACKEND_URL=http://localhost:3000

3️⃣  RUN BACKEND SERVER
    → mkdir ../empowerher-backend
    → cd ../empowerher-backend
    → npm install express dotenv twilio cors
    → Copy code from TWILIO_BACKEND_EXAMPLE.js to server.js
    → Create .env with Twilio credentials
    → node server.js

4️⃣  TEST IT
    → Add contacts in app
    → Click SOS button
    → Check phone for SMS + call ✅
